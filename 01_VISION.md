# Project Genesis - Vision

## Mission

Project Genesis is a modern virtual monster game inspired by the feeling
of classic handheld virtual pets, but built as its own original IP.

Core pillars: - Living companion - Short play sessions - Meaningful
growth - Social-first Bluetooth battles - Discovery through hidden
evolution paths

## Success

Players become attached to one creature, battle friends, experience
permanent death as a meaningful lifecycle, then eagerly hatch another
egg.

## Design Philosophy

Every feature must answer: \> Does this make the monster feel more
alive? If not, reconsider it.
